# src/lib/api

The single HTTP client for auth-service (and later other services). Built in phase 8 steps 2–3:
`openapi-fetch` + types generated by `npm run api:gen` from auth-service's OpenAPI schema, Bearer header,
`{"error","message"}` → `ApiError`, one refresh at a time. See the root README, "API client".
It never imports a store: its dependencies (`getAccessToken`, `refreshSession`, `onSessionEnded`) are passed in.
